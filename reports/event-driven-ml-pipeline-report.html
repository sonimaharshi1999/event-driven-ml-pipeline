Event-Driven ML Pipeline - Real-Time Stream Processing

Maharshi Soni · real-time-ai · advanced

Description

Event-driven stream processing for real-time ML inference. Async message broker, windowed aggregation, real-time features, online prediction. No external broker needed.

Tech Stack

fastapiuvicornscikit-learnnumpypandaspydanticpytest

Features

  • Async pub/sub broker
  • Tumbling and sliding windows
  • Real-time feature engineering
  • Online prediction
  • Dead letter queue
  • Monitoring dashboard

Sample Input

Event streams

python main.py --train && curl localhost:8000/events

Sample Output

Real-time predictions

{"event_id": "e_123", "prediction": "anomaly", "confidence": 0.91}
